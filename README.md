# BRITTON LIVE — متجر الألعاب الزوجية

## اسم مجلد المشروع
`britton-live-store`

## الملفات والمجلدات
- `index.html` — واجهة المتجر.
- `README.md` — تعليمات التعديل والنشر.
- `.nojekyll` — إعداد للنشر على GitHub Pages.
- `assets/products/` — ضع صور المنتجات هنا.

## أسماء صور المنتجات
ضع صورك في `assets/products/` بهذه الأسماء أو عدّل المسارات في `index.html`:
- `questions-cards.jpg` — بطاقات أسئلة للتقارب
- `30-day-challenge.jpg` — تحدّي 30 يومًا معًا
- `our-memories.jpg` — لعبة ذكرياتنا
- `choose-one.jpg` — بطاقات اختر واحدًا
- `fun-challenges.jpg` — عجلة التحديات اللطيفة
- `date-night.jpg` — ليلة موعد جاهزة

إذا لم تضع الصور، ستظهر رموز تعبيرية بدلاً منها. يفضّل أن تكون الصور JPG؛ وإذا استخدمت PNG أو WebP، عدّل اسم الامتداد في `index.html`.

## إضافة منتج جديد
في `index.html` ابحث عن `const products = [` ثم انسخ عنصرًا وعدّل `name` (الاسم) و`category` (الفئة) و`price` (السعر) و`desc` (الوصف) و`image` (مسار الصورة) و`emoji` (رمز بديل). الفئات الحالية: `أسئلة وتعارف`، `تحديات مرحة`، `جلسات وذكريات`.

## إعداد واتساب
في `index.html` ابحث عن `const WHATSAPP_NUMBER = "9677XXXXXXXX";` واستبدله برقم واتساب المتجر بصيغة دولية، أرقام فقط دون + أو مسافات.

## النشر
ارفع محتويات المجلد إلى جذر مستودع GitHub، بما فيها `index.html` و`README.md` و`.nojekyll` ومجلد `assets`. ثم افتح Settings → Pages واختر Deploy from a branch، والفرع `main` والمجلد `/(root)`.

الأسعار الحالية أمثلة بالريال اليمني؛ راجعها قبل البيع. الموقع واجهة ثابتة بطلبات واتساب فقط، ولا يحتوي على دفع إلكتروني أو قاعدة بيانات.
