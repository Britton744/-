# متجر بريتورا الفاخر — نسخة GitHub Pages

## الملفات
- `index.html` صفحة المتجر العربية RTL بتصميم أسود وذهبي فاخر.
- `.nojekyll` ملف مساعد للنشر.
- `README-SETUP.md` هذه التعليمات.

## النشر
1. فك ضغط ZIP على جهازك.
2. ارفع محتويات الحزمة إلى جذر الفرع `main` في مستودع GitHub (لا ترفع ZIP فقط).
3. اذهب إلى Settings → Pages.
4. اختر `Deploy from a branch` ثم `main` و `/(root)` إذا كان هذا هو مصدر النشر المطلوب.
5. انتظر اكتمال النشر من Actions ثم افتح رابط GitHub Pages.

## قبل استقبال الطلبات
- افتح `index.html` واضغط تعديل، ثم غيّر `STORE_WHATSAPP = "9665XXXXXXXX"` إلى رقم واتساب المتجر مع رمز الدولة، بدون + أو مسافات.
- عدّل أسماء المنتجات والأسعار والوصف لتطابق مخزونك الفعلي.
- هذه نسخة واجهة أمامية؛ نموذج الطلب يفتح واتساب فقط ولا يخزن البيانات أو يعالج الدفع الإلكتروني.
- لا تُعلن عن التوصيل أو الدفع عند الاستلام إلا إذا كان متاحًا فعليًا.
