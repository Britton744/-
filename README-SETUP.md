# متجر بريتون — ملفات جاهزة للرفع إلى GitHub Pages

## محتويات الحزمة
- `index.html`: واجهة متجر عربية متجاوبة مع نموذج طلب يرسل تفاصيل الطلب إلى واتساب بعد ضبط رقم المتجر.
- `.nojekyll`: ملف مساعد لنشر ملفات الموقع الثابت.

## طريقة التشغيل
1. فك ضغط ملف ZIP.
2. افتح مستودع GitHub الذي تريد نشر المتجر منه.
3. ارفع **محتويات المجلد** إلى جذر الفرع `main`، وليس ملف ZIP فقط.
4. تأكد أن `index.html` موجود بجانب `README.md` وداخل جذر المستودع.
5. افتح Settings → Pages واختر مصدر النشر المناسب. إذا كان النشر من فرع، اختر `main` والمجلد `/(root)`.
6. انتظر انتهاء النشر من Actions ثم افتح رابط GitHub Pages.

## قبل استقبال طلبات حقيقية
- افتح `index.html` وعدّل `STORE_WHATSAPP` إلى رقم واتساب المتجر مع مفتاح الدولة، دون + أو مسافات.
- عدّل المنتجات والأسعار والوصف لتطابق منتجاتك الفعلية.
- راجع تكاليف التوصيل وسياسات الاستبدال والاسترجاع والخصوصية.
- هذه الواجهة لا تعالج الدفع الإلكتروني ولا تخزن الطلبات في قاعدة بيانات. الطلب يفتح واتساب فقط بعد إعداد الرقم.
