مشروع BRITTON الجديد — دليل التشغيل

محتويات المشروع:
- index.html: واجهة المتجر.
- admin.html: لوحة التحكم المنفصلة.
- style.css: التصميم الوردي/الأحمر المتجاوب.
- store.js: المنتجات والسلة وإتمام الطلب ومساعد رُؤى الأساسي.
- admin.js: إدارة المنتجات والأقسام والطلبات والفواتير.
- firebase-config.js: إعدادات Firebase.
- firestore.rules: قواعد Firestore المقترحة.
- storage.rules: قواعد صور المنتجات والأقسام.

قبل النشر:
1) افتح firebase-config.js وأدخل apiKey وmessagingSenderId وappId من إعدادات تطبيق Web الحالي في مشروع Firebase britton-life-store. لا تنشئ مشروعاً جديداً.
2) تأكد أن البريد roooo77775@gmail.com مستخدم في Firebase Authentication، وأن طريقة Email/Password مفعلة.
3) دخول لوحة الإدارة: اسم المستخدم Rami، وكلمة المرور هي كلمة مرور حساب Firebase لهذا البريد. لم يتم تضمين كلمة المرور داخل الملفات لأسباب أمنية. إذا لم تكن كلمة المرور الحالية Rami12345، غيّرها من Firebase Authentication.
4) انشر firestore.rules في Firestore > Rules، وانشر storage.rules في Storage > Rules. اختبر على نسخة/بيانات تجريبية أولاً، ولا تستخدم قواعد allow read, write: if true.
5) ارفع جميع الملفات إلى جذر استضافة الموقع. رابط المتجر هو index.html ورابط لوحة التحكم هو admin.html.
6) مجموعات المنتجات والأقسام الإنجليزية هي المجموعات الأساسية التي تقرؤها الواجهة. المتجر يقرأ أيضاً مجموعة «منتجات» القديمة كحل احتياطي، لكن لوحة التحكم تحفظ المنتجات الجديدة في products. لا تحذف بياناتك القديمة.
7) صور المنتجات: حتى 8 صور، وتستطيع اختيار 4 صور أو أكثر.
8) الطلبات تحفظ في Firestore > orders، ويمكن طباعة الفاتورة من لوحة التحكم.

مهم — وظائف تحتاج إعداد خادم إضافي:
- إرسال الفاتورة تلقائياً إلى البريد: أنشئ Firebase Cloud Function أو خدمة بريد موثوقة، ثم ضع عنوان HTTPS في EMAIL_FUNCTION_URL. لا يمكن إرسال بريد موثوق وآمن من صفحة HTML وحدها.
- الذكاء الاصطناعي الكامل لرُؤى: أنشئ Backend يستدعي مزود AI مع API key محفوظ سرياً، ثم ضع عنوانه في AI_ENDPOINT. حالياً المساعد يجيب عن المنتجات الموجودة محلياً ويقدم ردود مساعدة أساسية.
- عداد الزوار الفريدين: يحتاج Cloud Function/عداداً آمناً منفصلاً. لا تعرض الواجهة رقماً وهمياً.
- رقم الهاتف الخاص لا يظهر في الواجهة العامة ولا يضاف إلى صفحات الاتصال. لم نضع رقمك في الملفات.

تنبيه توافق البيانات:
الكود القديم كان يتوقع products/categories وحقولاً إنجليزية، بينما بعض مستندات Firestore القديمة تستخدم حقولاً عربية أو مجموعة «منتجات». واجهة المتجر تحاول قراءة بعض الحقول العربية، لكن يفضل ترحيل بيانات المنتجات القديمة لاحقاً إلى مخطط موحد بعد أخذ نسخة احتياطية.
